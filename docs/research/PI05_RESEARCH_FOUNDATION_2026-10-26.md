4. **PI05.4 — Qualify an isolated pinned DuckDB candidate; gate optional Polars.** Freeze package/build/extension/runtime hashes and supported platform/profile. 6. **PI05.6 — Qualify bounded resources, failure and cancellation.** Run approved stress fixtures around memory/spill/output/task/deadline limits, near-full temp space, crashes/cancel/restart and malformed input. 7. **PI05.7 — Run registered comparisons and record the minimum sufficient decision.** Use identical admitted inputs/result contracts and candidate-specific plans/settings; retain every run, failure and cache condition. Report full-job effect and uncertainty plus RSS/spill/I/O/scan counts and all parity/security gates.
