# Prior production raw-codec fixture

`f07-parquet-pyarrow-v1.parquet` was sealed by the unmodified F07 implementation
exported from Git merge commit `aa5ad35` (PR #7), before F08–F11. The JSON sidecar
records the full revision, dependency/runtime versions, exact raw projection,
encoded/logical lengths and SHA-256. It is a fixed compatibility vector, not a
file regenerated by the current writer during the test.

The single `collector-a` / `epoch-a` / offset 7 record uses the existing F07
`tests.normalization.helpers.raw_record` defaults, with exact payload
`b'\x00\xffprior-codec\n{"exact":true}'`. Seal limits were 4 records / 100,000
encoded / 100,000 logical decoded bytes. The generator used the historical
`ParquetRawArchive.seal` and copied its installed content-addressed file.

Object SHA-256: `f7d43f0b6eededc7cdea5b8c4c656904595eb59d4eab1f9c79c650677eccc883`.
The fixture was generated with the current locked dependency environment;
provenance does not claim a historical machine/native-library binary. Future
writers need not reproduce identical Parquet bytes, but existing readers must
preserve this archived identity, complete envelope and binary payload.

Decoder selection in the compatibility test is fixed local code. Neither the
JSON sidecar nor a manifest names an importable module or executable handler.
